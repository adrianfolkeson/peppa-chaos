# 🎮 PEPPA CHAOS

A chaotic 2D pixel art game where you cause mayhem and escape!

## 🌟 Features
- 6 unique levels
- Chaos meter gameplay
- Escape sequences
- Boss fights
- Pixel art style with glitch effects

## 🎮 Controls
- WASD / Arrow Keys: Move
- SPACE: Action
- ESC: Pause

## 🚀 Quick Start
```bash
cd web
# Open index.html in browser
```
